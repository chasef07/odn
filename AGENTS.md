# Agent rules

Run `npm run check` before every push. CI runs the same command on every pull request.

Each rule below names the check that enforces it. A rule that no check enforces does not belong in this file.

| Rule                                                                                                                                                                                                                              | Enforced by                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Code is formatted with Prettier. Run `npm run format` to fix it.                                                                                                                                                                  | `npm run format:check`                                                            |
| ESLint passes with zero warnings.                                                                                                                                                                                                 | `npm run lint`                                                                    |
| No comments in JS or TS files, except tool directives such as `eslint-disable` and `@ts-expect-error`. Run `npx eslint --fix` to delete them.                                                                                     | `eslint-rules/no-comments.mjs`, in `npm run lint`                                 |
| No comment lines in YAML, TOML, Dockerfiles, ignore files, `.env` files, the Prisma schema or JSON. A shebang and leading Dockerfile parser directives are allowed. `prisma/migrations` is skipped because it is applied history. | `scripts/check-comments.mjs`                                                      |
| Source files and test files typecheck.                                                                                                                                                                                            | `npm run typecheck`, with tests included by `tsconfig.json`                       |
| An intake step page has no `setError` call. A rule belongs in its step schema in `src/lib/validation-schemas.ts`, so the server runs it too.                                                                                      | `src/lib/__tests__/intake-step-pages.test.ts`, in `vitest run`                    |
| A rule that `main` enforced at checkout before shadow mode is `always` in `src/lib/intake-rules.ts`, so it blocks checkout whatever `INTAKE_VALIDATION_ENFORCED` says. Only a rule marked `flag` follows the flag.                | `src/lib/__tests__/intake-checkout-differential.test.ts`, in `vitest run`         |
| Tests pass.                                                                                                                                                                                                                       | `vitest run`, in `npm run check`                                                  |
| Every npm script, `npx` tool and repo path named in `AGENTS.md` or `README.md` exists.                                                                                                                                            | `scripts/check-doc-refs.mjs`                                                      |
| Server code reads env vars only through `env` in `src/lib/env.ts` and `publicEnv` in `src/lib/public-env.ts`, never `process.env`.                                                                                                | `eslint-rules/env-sdk.mjs` (`local/no-process-env`), in `npm run lint`            |
| SDK clients (`Stripe`, `Resend`, `PrismaClient`) are constructed only in their owner module.                                                                                                                                      | `eslint-rules/env-sdk.mjs` (`local/no-sdk-client`), in `npm run lint`             |
| Config is read and SDK clients are built inside functions, never when a module is imported.                                                                                                                                       | `eslint-rules/env-sdk.mjs` (`local/no-import-time-config`), in `npm run lint`     |
| The server exits at startup, naming each variable, when a required env var is missing or invalid.                                                                                                                                 | `src/instrumentation.ts` and `src/lib/env.ts`                                     |
| Every admin server action is built with `adminAction`.                                                                                                                                                                            | `eslint-rules/admin-server-action.mjs` (`admin/server-action`), in `npm run lint` |
| The Prisma schema is valid.                                                                                                                                                                                                       | `npx prisma validate`, in `.github/workflows/ci.yml`                              |
| The production build succeeds.                                                                                                                                                                                                    | `npm run vercel-build`, in `.github/workflows/ci.yml`                             |
